# Projektuppgift - Proggrammering i C# .NET  -  Mittuniversitetet 

Detta är en avslutande projektuppgift i kursen Programmering i C# .NET vid Mittuniversitetet. 

Uppgiften syftar till att visa på kunskaper från kursens gång i ett större sammanhängande projekt tillsammans med ett valfritt ramverk i .NET.

I detta projekt har en webbapplikation skapats med Blazor WebAssembly. Denna applikation ger användaren möjlighet att skapa och hantera en To-Do-lista genom att lägga till nya uppgifter, markera uppgifter som slutförda och radera uppgifter. Data lagras med hjälp av JavaScript i webbläsarens LocalStorage.

## 🌟 Syfte
Syftet med projektet är att visa på kunskaper inom objektorienterad programmering med C# tillsammans med det valda ramverket. 

## Tekniker

- C#
- .NET 10
- Blazor WebAssembly
- Razor
- HTML och CSS
- JavaScript
- LocalStorage

## Köra projektet

1. Klona eller ladda ner projektet från GitHub.
2. Öppna projektmappen i Visual Studio Code.
3. Öppna terminalen i projektmappen.
4. Kör `dotnet run`.
5. Öppna den lokala adressen i webbläsaren.
